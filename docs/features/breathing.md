# 呼吸引导

状态：需求已整理，待实现。更新日期：2026-11-14。

## 目标与已确定事项

- 工作台任意页面固定入口，一键打开；第一版仅在工作台内使用。
- 用户手动发起，暂不让 Agent 判断使用场景或主动发起练习。
- 短暂准备后直接开始，沿用上次选择；不每次填写设置。
- 沉浸覆盖层保留原页面与草稿，支持可选全屏。
- 纯画面引导；声音、语音和环境音不进入第一版。
- 默认两分钟，提供 1／2／5 分钟及不限时；剩余时间弱显示。
- 本地简短记录，结束反馈可跳过。第一版不自动向模型发送练习反馈；以后需要 Agent 分析时再确定入口和范围。
- 练习期间暂停工作台的所有提醒弹出，包括到点提醒。后台任务继续，消息继续进入收件箱并保留未读。
- 结束后只显示一条“期间有 N 条提醒”，点击查看对应消息；不逐条补发桌面通知。没有新提醒时不显示数量提示。
- 呼吸节奏由开发者查证并提出设计，用户只需按体验反馈调整。
- 切换其它软件或浏览器标签页时自动暂停，返回后短暂准备再继续；暂停期间不累计有效练习时长。

## 第一版设计提案

默认采用吸气 4 秒、呼气 4 秒、无屏息。圆形平滑放大对应吸气、缩小对应呼气，配合明确的阶段文字；允许简单调快／调慢。两分钟是低门槛入口的产品选择，不声明为保证效果的医学时长。

开始前留约 3 秒准备；准备阶段不要求改变呼吸。暂停时提示自然呼吸；恢复时重新准备后进入新周期，不从屏息或半周期硬接续。结束时完成当前呼气后收尾，实际时长与计划时长分别处理。退出随时可用，关闭全屏回到覆盖层，退出覆盖层回到原页面。

视觉暂定沿用工作台配色，用低亮度柔和圆形，保持正文可读；不加入未选定的角色或风景素材。提供减弱动效／文字引导替代。设置不影响首次进入的简洁流程。

本地记录建议字段为开始时间、实际持续时间、所选节奏、结束／提前退出，以及可跳过的主观反馈。不推断压力水平或呼吸是否合格，不自动生成医学结论。

## 提醒与生命周期设计约束

当前通知有后端 Web Push 与前端 SSE → Service Worker 两条路径。实现时必须覆盖两条，不能只在覆盖层隐藏提示，也不能将尚未展示的消息写成已读。

需考虑多标签页、刷新、关闭页面、电脑休眠与长连接断开。暂停状态应能按会话结束或失效恢复，避免永久静默；迟到推送与已在途请求不得丢失。练习结束后的汇总仅覆盖此次暂停期间新增且仍未读的提醒。历史提醒保留原状，去重与点击定位沿用既有机制。

页面被关闭／刷新时按提前结束处理并恢复提醒；切换其它应用或标签页按用户确认自动暂停，返回后准备再继续。暂停期间的提醒仍保留，避免在暂时离开练习时突然补发。关闭／崩溃和失效回收须与普通暂停区分。

## 资料与设计依据

- [NHS 呼吸练习](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/)：轻柔、规律、在舒适范围内呼吸；允许按自己的节奏数数。
- [慢呼吸与吸呼比例随机试验](https://pmc.ncbi.nlm.nih.gov/articles/PMC10395759/)：没有证实延长呼气相较等长吸呼具有显著的减压优势；不把某一比例视为人人适用。
- [W3C 动效说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)：尊重减少动效的偏好，提供可替代的信息表达。
- [Breathing](https://breathing.dev/)：圆形缩放与节奏交互参考。
- [Mindful Breathe](https://github.com/kosciukus/breathe)：预设和提示交互参考；当前不引入其代码或素材。

资料用于提出温和、可调整的引导设计；出现不适时可以停止并恢复自然呼吸。
