# 日常操作与页面联动

更新：2026-11-25。代码已实现，尚未构建、重启或进行实机验收。

## 提醒与托管事项

- 首页、提醒箱和消息正文共用「知道了」「今天已做」「查看事项」。已读只处理消息，今天已做记录当日确认并静默到北京时间次日零点。
- 当日确认后可「撤销今天已做」，恢复确认前的静默期限，重新计算后续周期触发。原确认和撤销各自保留时间线记录。已有更长静默期限和后来调整的静默期限继续保留；已读消息不重新变成未读。
- 事项卡和详情共用现在检查／提醒、暂停、启用／恢复、编辑、其他处理、带上下文到对话和结束事项。静默期内立即执行按钮显示静默截止时间并禁用。结束只终止后续安排；已经运行的回合仍由「终止本次执行」处理。
- 托管列表可同时按名称／说明、类型和状态筛选。
- 主动通知新增 `notificationCadence`：`daily` 按事项时区的自然日每天最多一次；`interval` 按 `minimumGapMinutes` 的实际间隔控制。旧数据未指定模式且间隔为 1440 分钟时使用自然日，其他间隔保留原语义。明确的到点提醒继续按排期发送。

## 待办

- 首页近期事项可直接完成或打开编辑。待办页把今天、逾期、之后／待安排和已完成分开显示。
- 快速添加支持折叠的日期、时间和说明，默认今天。编辑和从对话／决策结果加入待办共用今天、明天、清除日期和只保留日期操作。
- 编辑通过固定版本 OpenTodo 的 REST PATCH 一次提交标题、说明和完整 `due`，可以真正清除时刻或日期。保存前重新读取并比较页面所见字段，变化时提示重新打开。
- 可移入 OpenTodo 回收站，从完整看板恢复。编辑和移入回收站均保留操作来源及时间；完成判断仍使用原来的来源与核查机制。
- 上游依据：[OpenTodo v1.4.2 collection REST](https://github.com/OpenTodoApp/OpenTodo/blob/v1.4.2/internal/httpapi/collections.go)、[MCP schedule_tasks](https://github.com/OpenTodoApp/OpenTodo/blob/v1.4.2/internal/agenttools/write_tasks.go)。此版本 MCP 排期对省略的时间保留旧值，因此这里采用完整日期对象的 REST 更新。

## 对话与查找

- 回复期间可继续输入和发送，新消息进入现有持久队列，按序处理；停止按钮继续取消当前回复和排队消息。
- 「新话题」建立新的 Codex 聊天会话与话题范围，保留已有聊天历史。执行或排队期间先完成／停止后再切换。新话题的自动上下文限于本话题；长期记忆及主动检索仍然可用。
- 聊天可选全部、只看对话、只看提醒。提醒箱可只看未读和全部已读；从其他页面打开具体消息时自动恢复可见范围并定位。
- 消息「保存到…」预填待办、托管事项、工具箱或笔记表单；确认后写入对应功能。托管事项默认待接管。当前保存的是文字，图片继续保留在原消息。
- 全局搜索支持 Ctrl／Cmd+K，关闭后保留本次页面会话的关键词和结果。结果可直接打开具体待办、托管事项、消息、工具、笔记或执行记录；其他类型在所属页面打开原文。
- 所有页面都有待审批提示，可进入对话处理。

## 笔记、工具和设置

- 笔记先以可点击链接的阅读模式打开，再选择编辑、重命名或移到本机 `memory/.trash` 回收站；目前从文件夹恢复。重命名会更新工具关联及工作台记录订阅的引用，历史证据哈希保持原样以便重新核对。外部文件路径和自由文本中的旧名称不自动替换。
- 工具支持标签筛选、带工具引用进入对话、归档和恢复。归档工具可通过「包含归档」找回。
- 答案之书翻开后仍可点击书页抽取下一页。决策结果加入待办时可直接选择日期和时间。
- 设置同步外部更新过的字段；聊天／后台执行期间仍可保存唤醒和免打扰设置，模型切换需等当前执行结束。只改变免打扰不重新推迟下一次唤醒。
- Codex 登录按钮直接打开官方返回页面，并保留链接供弹窗被拦截时使用。Moraine 提供复制令牌并打开管理页的合并操作。
- Codex 每轮记录 Moraine 自动查询的状态、时间、正文或错误；完成的聊天执行过程、后台执行详情均可查看。状态快照仅含状态，展开详情时读取正文。Magpie 不增加记忆调用。

## 代码与交付边界

共用操作位于 `web/src/JobActions.jsx`、`ReminderActions.jsx`、`TaskDateFields.jsx`、`CreateTask.jsx`、`MessageSave.jsx`。后端复用现有队列、通知、任务来源记录和 OpenTodo 服务，没有新建任务或记忆管理子系统。

本批仅阅读代码、上游固定版本源码和 Git 差异，没有运行测试、类型／语法检查、lint、构建或浏览器验证，没有重启或操作真实任务。跨日撤销、排队、表单保存、回收站、登录跳转和页面布局需要加载后验收。没有新增依赖。运行数据不随源码提交。
