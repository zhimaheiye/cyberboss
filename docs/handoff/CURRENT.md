## 当前批次

基线 `0fe2c10`。本批补齐 Magpie 的配置和实际执行入口：

- 设置页配置本机地址、可选密钥、拉取模型、默认模型、请求次数／输出上限和交回 Codex 开关。
- 托管事项可选 Codex、Magpie、自动（技能 ready 时优先 Magpie），可单独指定模型；既有事项继续默认 Codex，主对话与自然唤醒仍用 Codex。
- Magpie API 执行器复用工作台工具、运行归属、浏览器协调和完成／核验记录；无法使用 Codex 独有 MCP 或通用本地系统工具时交回 Codex。

详见[Magpie 接入](../features/magpie.md)。连接配置与密钥保存在原本机数据目录的 `magpie/settings.json`，不提交源码仓库。
