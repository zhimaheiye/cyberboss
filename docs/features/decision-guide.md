# 减少决策

更新：2026-11-16。第一版接入工作台，尚未构建、重启或进行浏览器验收。

## 目标与范围

将已有独立 HTML 分支工具和场景笔记融入工作台。第一版保留原型中的选择流程，分支内容后续会调整，因此将内容与界面分开，并提供表单编辑。

- 侧栏「减少决策」进入，包含「开始选择／场景与分支／原始笔记」。
- 场景卡片进入逐步问答，选项前往下一问题或结果。可返回上一步、重新开始或返回场景列表。
- 结果支持手动加入待办、带到对话草稿、打开待办页。不会自动提交对话、创建任务或代表用户完成实际行动。
- 场景名称、说明、入口、问题、结果、选项和跳转都可在页面修改。支持新建场景、节点、选项及删除；保存前检查空白内容、无效连接和循环。
- 编辑窗口关闭放弃草稿，保存使用版本号防止覆盖其他页面的修改；成功保存后重新选择场景。
- 当前选择仅保留在页面内存，切换工作台页面仍保留；刷新或关闭页面后清空。加入待办时才持久化选择路径及结果，不自动生成生活时间线记录。

## 首次迁入与隐私

本机已将旧三问流程的选项／结果转换成分支图，保留所有三次提问；另将旧控制中心的饮食分支转换为第二个场景。原始 HTML 备份与三份 Markdown 笔记留在本机，源目录保持原样。

公开代码只带通用示例，不包含上述个人内容。笔记以纯文本展示，不执行 HTML、DataviewJS、文件链接或其中的规则。原规划中的时间推荐、设备控制、应用启动、健康相关规则均未启用。

默认数据位置（跟随工作台数据目录配置）：

| 文件 | 用途 |
| --- | --- |
| `data/desktop/decision-guide/guide.json` | 场景和分支，格式版本 1，带递增 revision |
| `guide.previous.json` | 每次修改前的上一版，仅本机 |
| `sources/*.md`、`sources/*.txt` | 页面可阅读的原始参考笔记 |
| `original/` | 迁入时保留的原文件，不在页面执行 |

整个目录均被 Git 排除。源码推送不会备份个人分支或笔记。
