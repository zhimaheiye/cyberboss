## 2026-11-14：自主恢复

- 根因：连接等待窗口过短，随后依据历史缓存转交用户；没有用实时状态复查。
- 改为保留健康连接、有限等待、宿主浏览器诊断、明确条件下恢复原配置；请求派发前读取实时状态，已派发动作不自动重放。
- Agent 阻塞任务需记录恢复尝试、现场证据、人工接手原因；暂时离线且无业务副作用的循环任务保留周期。
- 更新提示词与维护页面。实际只读取既有日志和连接状态，没有重跑原业务动作；新机制未在该轮重启部署，未执行测试／构建／浏览器交互验证。
