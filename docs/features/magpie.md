# Magpie 模型接入与任务分配

## 界面入口

「设置 → Magpie · 低成本模型」配置本机服务地址、可选 API Key、默认模型、每轮请求次数与输出上限。默认地址为 `http://127.0.0.1:3425/v1`，也接受服务根地址。点击「拉取模型」使用当前表单中的地址与密钥读取模型目录，无需先保存，也不调用生成模型。选择模型、开启启用开关并保存后生效。密钥不回显；换地址后不携带旧密钥。

「交给 Agent → 编辑 → 交给谁执行」提供：

| 选择 | 行为 |
| --- | --- |
| Codex | 使用本机订阅与原 MCP 能力；既有事项默认保持此项 |
| 自动 | Magpie 已启用且该事项技能状态为 ready 时使用 Magpie，否则使用 Codex |
| Magpie | 使用设置页的默认模型，也可为此事项单独选择模型 |

提醒类事项直接投递，仍无需模型。聊天与自然唤醒由 Codex 处理。Agent 可以建议任务分配，但执行者和模型选择由用户通过界面设置。全局关闭 Magpie 后，后续事项使用 Codex；正在执行的回合保留启动时配置。

## 实际执行

Magpie 使用兼容的 Chat Completions function tools 回合执行已有流程。它收到任务材料、进展和技能，可使用进展读取与报告、来源核验、浏览器维护、观察、完成时间线、工具箱与 OpenTodo。Moraine、全局检索、Markdown 记忆工具及个人偏好注入仅供主 Agent 使用。浏览器操作继续使用同一占用机制，完成判断保留 Agent 来源。

Magpie 不继承 Codex 配置的所有 MCP，也没有通用 shell／任意文件读写工具。它可返回 handoff 说明能力缺口，交由 Codex 继续。浏览器技能文档从本机已安装的 kimi-webbridge 读取；缺少该文档时浏览器步骤交回主 Agent。工具箱仅供读取，进展工具仅开放 read/report，不允许 API 执行器改派任务或管理模型配置。

单次模型请求超时 120 秒，模型回合默认最多 6 次、单次输出上限 4096 tokens；设置可调整请求次数与输出上限。后台 API 执行总体有 8 分钟时限。工具调用串行处理，记录输入、输出、错误与耗时。取消后停止后续请求／工具派发，在途工具按已有机制结算。

默认开启交回 Codex：API 错误、额度限制、格式问题、主动能力交接、请求上限，以及 watch 核验未完成或结果不确定时，把本轮步骤、错误、来源尝试和进展带给 Codex。提示其先读取现状核对已执行动作，补完缺口；不会由调度代码直接重放工具调用。用户取消或任务不再 active 时不启动交接。关闭回退后，未完成状态沿用现有失败／监控重试规则。

这不是两个模型同时执行同一事项；两者共用一条后台通道、同一 run，日志展示 `Magpie → Codex`。自动分配基于当前配置和已验证技能，不额外调用模型做路由判断；技能 ready 表示既有流程有成功证据，不保证每个 API 模型都能一次执行成功。用户可根据实际记录调整选择。

## 主 Agent 的小任务委派

`cb_delegate(instruction,context)` 允许 Codex 把提取、整理、比较、摘要交给默认 Magpie 模型。这个委派只有文本输入输出，不配工具；主 Agent 负责核对来源和决定后续操作。每轮委派次数也受设置的请求次数上限约束。Magpie 已交回 Codex 的回合不再接受反向委派，避免循环。

执行记录保存路由原因、模型、请求次数、返回的 token 用量、交接原因以及文本委派的目的和状态。价格和实际计费由 Magpie 管理，不按模型名称估算费用。当前没有接入独立的 rerank endpoint；文本比较／排序可使用委派工具，已有 embeddings 设置仍独立维护。

## 数据和接口

连接配置及密钥仅保存在当前数据目录 `magpie/settings.json`，模型目录仅在内存缓存，启动后可以再次拉取。选中的任务说明、进展、必要技能和工具返回会经 Magpie 发送到所选服务。API 凭据不放入模型上下文，错误与工具日志做遮盖；模型私有推理不保存。

接口采用 [模型列表](https://developers.openai.com/api/reference/resources/models/methods/list) 与 [Chat Completions](https://developers.openai.com/api/reference/resources/chat) 的兼容格式。此处的正式文档说明请求结构，Magpie 各上游模型的兼容性仍需实际验证。

实现：`src/desktop/magpie.js`、`magpie-agent.js`、`agent-pool.js`、工作台路由和工具；`web/src/MagpieSettings.jsx`、事项编辑及执行记录。
