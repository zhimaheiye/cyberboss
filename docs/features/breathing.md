# 呼吸引导

2026-11-14 已实现第一版；2026-11-15 调整默认节奏并增加模式切换，待实际使用验收。

## 目标与已确定事项

- 工作台任意页面固定入口，一键打开；第一版仅在工作台内使用。
- 用户手动发起，暂不让 Agent 判断使用场景或主动发起练习。
- 短暂准备后直接开始，沿用上次选择；不每次填写设置。
- 沉浸覆盖层保留原页面与草稿，支持可选全屏。
- 纯画面引导；声音、语音和环境音不进入第一版。
- 默认两分钟，提供 1／2／5 分钟及不限时；剩余时间弱显示。
- 本地简短记录，结束反馈可跳过。第一版不自动向模型发送练习反馈；以后需要 Agent 分析时再确定入口和范围。
- 练习期间暂停工作台的所有提醒弹出，包括到点提醒。后台任务继续，消息继续进入收件箱并保留未读。
- 结束后只显示一条“期间有 N 条提醒”，点击查看对应消息；不逐条补发桌面通知。没有新提醒时不显示数量提示。
- 呼吸节奏由开发者查证并提出设计，用户只需按体验反馈调整。
- 切换其它软件或浏览器标签页时自动暂停，返回后短暂准备再继续；暂停期间不累计有效练习时长。

## 第一版行为

默认采用吸气 4 秒、呼气 6 秒、无屏息。圆形在吸气的 4 秒内平滑放大，在呼气的 6 秒内缩小，倒计时分别计算。可在「练习设置 → 呼吸模式」切换到等长吸呼，等长模式保留 3／3、4／4、5／5 秒三个选项，均无屏息。两分钟是低门槛入口的产品选择，不声明为保证效果的医学时长。

切换模式或等长节奏后，短暂准备再开始新的呼吸周期；有效练习累计时长保留。界面持续显示当前吸呼秒数。旧版仅保存 `pace` 的浏览器设置首次使用新版时采用延长呼气模式，保留原时长、减弱动效与等长节奏偏好；此后记住用户选择的模式。

开始前留 3 秒准备。暂停时提示自然呼吸，恢复时重新准备后进入新周期。到达设定时长后完成当前呼气再收尾。退出随时可用，关闭全屏回到覆盖层，退出覆盖层回到原页面。

界面沿用工作台的绿色系，以低亮度背景和柔和圆形引导呼吸。减弱动效可在练习设置里开启，也会遵循系统的减少动效偏好。

本地记录包含开始与结束时间、有效练习时长、所选节奏、结束状态及可选反馈。时长与节奏偏好保存在当前浏览器。练习记录随工作台数据保存，可在练习设置中查看最近十次。

新记录保存结束时的模式和吸气／呼气秒数；一场练习内切换模式时不分段记录。旧记录仍按原来的等长 `pace` 显示，不将旧记录改写为 4／6。新后端兼容尚未刷新的旧页面，将只发送 `pace` 的请求识别为等长模式。

## 提醒与生命周期设计约束

开始练习时，服务端登记当前会话，从此暂停发出 Web Push。练习期间创建的提醒会记录对应会话并保留原来的未读状态，结束后通过页面汇总查看。页面通知与 Service Worker 在弹出前也会检查会话状态。已经交给浏览器推送服务的在途消息受浏览器策略影响，Chromium 可能自行显示通用通知。 [Chromium 的推送处理](https://chromium.googlesource.com/chromium/src/+/main/chrome/browser/push_messaging/push_messaging_service_impl.cc)

同一工作台同时允许一个会话。页面每 15 秒报告进度，失去焦点或切换标签页时也会报告一次。连续 150 秒未收到进度时，服务端按中断结算并恢复提醒；记录以最后收到的进度为准。刷新或关闭时页面尝试提前结束，进程重启时结算遗留会话。

汇总涵盖尚未收起的已结束练习中新增且仍未读的提醒。点击单条按原消息定位打开，收起汇总只关闭该入口。暂停期间继续保留提醒，直到练习结束或会话失效。

## 资料与设计依据

- [NHS 呼吸练习](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/)：轻柔、规律、在舒适范围内呼吸；允许按自己的节奏数数。
- [慢呼吸与吸呼比例随机试验](https://pmc.ncbi.nlm.nih.gov/articles/PMC10395759/)：在 12 周干预中未发现两种比例的显著组间差异；不能据此断定短时练习效果完全相同。
- [延长呼气与高频心率变异性](https://pubmed.ncbi.nlm.nih.gov/34289128/)：短时生理指标为延长呼气提供参考，不能直接等同于主观舒缓效果。4／6 是经用户确认的可调整产品默认值，不宣称为普遍最优参数。
- [W3C 动效说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions)：尊重减少动效的偏好，提供可替代的信息表达。
- [Breathing](https://breathing.dev/)：圆形缩放与节奏交互参考。
- [Mindful Breathe](https://github.com/kosciukus/breathe)：预设和提示交互参考；当前不引入其代码或素材。

资料用于提出温和、可调整的引导设计；出现不适时可以停止并恢复自然呼吸。
