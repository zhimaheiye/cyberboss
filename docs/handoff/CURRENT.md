## 当前批次

基线 `13444f4`。本批实现 Super Agent 调研中适用于当前工作台的持续任务机制：

- 聊天／后台两个执行通道；聊天、自然唤醒及每项作业分别持久化 Codex 会话。工具调用带通道，完成来源、核验与观察绑定实际运行。浏览器桥接按整轮占用并串行派发。
- 原托管事项增加持久进展、用户补充、工作台记录／单文件／外部事件订阅；来源变化进入待处理事件，进程按原任务状态调度。提醒理由与系统实际投递结果分别保留。
- 首页和托管详情统一展示进展与需要处理的事项，原导航保留。个人工作偏好可编辑、查看版本与默认指令快照。技能增加适用条件与重新核验条件。
- 进展、事件参与统一检索；用户补充和进展证据保留，普通来源事件随符合 7 天策略的正常运行清理。
- 只读查看本机 Magpie 接口说明与模型目录，记录单一 API 渠道及任务分工建议。尚未接入其模型执行器、未调用模型或修改任务路由。

详见[持续任务与事件](../features/continuous-work.md)。所有运行数据继续留在本机原数据目录；本批未改写现役数据。
