# 答案之书

2026-11-14 首版源码已接入；未构建、未重启服务、未进行浏览器交互验收。

## 已确定的体验

- 侧栏独立入口「答案之书」，内部提供「翻书」「句子池」「收藏」。本轮不增加全局快捷按钮。
- 深绿封面、金色细线和暖白书页。点击封面或「翻开一页」揭晓，支持再次抽取；遵循系统的减少动效设置。
- 问题可填可不填。问题不会发给模型，也不参与选句；每次从选定范围的已启用句子里等概率随机抽一句。
- 范围可选通用句库、我的句子、混合句库。相同文本去重后参与抽取，混合时优先使用个人句子的来源标记。允许连续抽到同一句，不额外加权或排除上一句。
- 普通问题和抽取结果仅存在当前页面内存中，离开此功能或刷新后不恢复。只有点击收藏时才保存当时的问题和答案快照；后来编辑、停用或删除句子不改写收藏。
- 本轮不接入 Agent 的主动触发、解读或记忆检索，不调整原提醒机制。

## 无需改代码的句库管理

「句子池」可分别浏览与搜索两个库，提供分页及启用／停用。个人句子支持新增、编辑、删除；通用句子支持停用或修改后另存到个人库。

批量导入可选择目标库，粘贴每行一句的文本，或选择 UTF-8 TXT / JSON 文件。JSON 支持文字数组、包含 `entries` 数组的导出文件，以及来源项目的数字编号／`answer` 格式。文件最多 800 KB，每句 1～600 字，两个库合计最多 10000 句。导入先检查整批内容，格式错误不部分写入；同库重复内容跳过，保留已有停用状态。

句库可导出 JSON，包含文本和启用状态。收藏单独导出，包括问题和答案；目前不提供收藏导入。收藏上限 2000 条，取消收藏需要确认。多页面同时使用时，通过「刷新」读取其它页面的句库变更；个人句子的编辑保存会检查原文是否已被修改。

## 通用句库与公开边界

源码仓库只包含功能、下载入口与来源说明，不附带任何默认答案文本。下载的通用句子、用户自己添加的句子和收藏都保存在运行数据目录，不随 Git 提交。

当前可选下载来源为 [A-kirami/answersbook](https://github.com/A-kirami/answersbook) 的 [answersbook.json](https://github.com/A-kirami/answersbook/blob/master/answersbook.json)。上游 README 说明文本录自《神奇的答案之书》，书目信息以来源说明为准。这里记录下载位置，不把第三方文本列为 CyberBoss 开源内容。

新安装可以在页面中点击「下载通用句库」，或在仓库根目录明确执行：

```sh
node scripts/install-answer-book.js
```

下载不会在 npm 安装或工作台启动时自动发生。它只访问固定的来源 URL，保留下载时间及 SHA-256，导入时去重。Node 下载链路失败时尝试系统 curl；都失败则显示文件导入方式，保留已有句子。整理过的句子不会因补充下载而重新启用。

数据默认位于 `data/desktop/answer-book/`，遵循 `CYBERBOSS_DESKTOP_DIR`：

| 文件 | 内容 |
| --- | --- |
| `library.json` | 通用／个人句子、启用状态、收藏快照与来源元数据 |
| `downloaded-source.json` | 下载的第三方原始句库，仅本机保留 |

需要备份个人内容时可以导出，或在停止写入后备份此目录到私有位置。源码已经推送不代表这些数据已备份。

## 实现与依赖

- `web/src/AnswerBook.jsx`：阅读界面、导入编辑、收藏与下载。
- `web/style.css`：布面封皮、纸张、书页和管理页面样式。
- `src/desktop/answer-book.js`：独立数据文件、导入去重、等概率抽取与主动收藏。
- `src/desktop/server.js`：沿用本机认证的 `/api/answer-book` GET / POST。普通抽取不写入聊天、历史、Agent 上下文或数据库。
- 翻页使用 [GulLabs flipbook-core](https://github.com/gul-labs/flipbook)，固定版本 `3.2.2`，沿用其 MPL-2.0 许可，依赖源代码与许可可从该仓库和 npm 包获得。它继承 StPageFlip 的翻页实现与 MIT 声明；本项目未修改或内嵌其引擎源码。运行要求为 Node 22.18 或更高。
- 采用该分支是因为原版 `page-flip@2.0.7` 的销毁方法不停止帧循环；当前分支的销毁路径包含停止渲染。界面退出时调用销毁，动画初始化失败时保留静态书页显示。
